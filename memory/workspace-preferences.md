 All deliverables and outputs intended for user review must be written under `C:\workspace\claude` using these subdirectories:
 - `research/` — Structured research reports (MD/HTML)
 - `docs/` — Documentation files
 - `files/` — General file outputs, data exports
 - `code/` — Code deliverables, scripts, notebooks
 
 Reports should follow the pattern `research/YYYY-MM-DD-topic.md` and HTML dashboards go to `code/topic.html`.
 
 **Why:** User needs a clean paper trail with separated concerns — research, docs, code, and general files each in their own folder for easy navigation and retrieval. 
 
 **How to apply:** When producing any artifact intended for user review or as a final deliverable, route it to the appropriate subdirectory under `C:\workspace\claude`.
